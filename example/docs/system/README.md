# Note Desk System Reference

Note Desk is a small synthetic application demonstrating revision and approval documentation. It runs entirely in a browser. Its data is disposable; it has no server, real authentication or deployment acceptance.

Read [Architecture](architecture.md), [Domain model](domain-model.md), [Workflows](workflows.md) and the [worked example](worked-example.md). See the [User guide](../user/README.md) for tasks and the [Engineering review](../reviews/README.md) for limitations.

The example API browser is a separate illustrative contract, not a service implemented by this demonstration. This distinction is intentional.

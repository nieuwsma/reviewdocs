# Code synthesis

## Sources read

The example workflow seam and browser controls are the production demonstration sources. The Node producer exercises immutable earlier text, explicit approval, invalidation and stale-save refusal.

## Limits

The UI uses its own current version when saving. The core function's stale-save check does not establish multi-tab coordination. Storage exceptions retain in-memory state with an alert. Browser behavior and print/accessibility acceptance remain separate from Node assertions.

# Troubleshooting

| Symptom | Check first | Safe next action |
| --- | --- | --- |
| Empty text error | Draft text contains a nonblank note | Enter the example text and save |
| Approve is disabled | A saved revision exists and draft matches saved text | Save or discard your draft, then inspect saved text |
| Storage error | Browser permits local storage | Keep displayed text; avoid claiming durable save; use an allowed browser |
| Example starts with old text | Browser retained demo state | Choose Reset demo for disposable data |

When reporting a problem include the attempted action, displayed version and exact error. No credentials or private data belong in this example.

# Review and approve

## Before you begin

Save a note first. Inspect its **Saved text**, not only the draft.

## Steps

1. Choose **Approve current** after reading the saved {{revision}}.
2. Confirm status **Approved version 1**.
3. Change **Draft text** and choose **Save revision**.

## Expected result

The new revision is **Pending approval**. Earlier approval does not authorize changed text. Unsaved changes disable **Approve current** until saved or discarded.

## Conflict and recovery

A stale save is rejected by the workflow. Refresh and inspect saved state before retrying. This demonstration does not implement multi-user or multi-tab conflict coordination.

# Getting started

## Before you begin

Use a browser with JavaScript enabled. The example contains disposable synthetic data and requires no account. A real product guide should describe its actual deployment/account handoff.

## Open the workspace

1. Open Note Desk using the separate synthetic test fixture.
2. Check the heading **Note Desk — synthetic demo**.
3. To start clean, choose **Reset demo**.

## Expected result

The form shows a draft and a saved-version status. The demo's controls run the actual example workflow. Their appearance is not proof of production permissions or a deployed backend.

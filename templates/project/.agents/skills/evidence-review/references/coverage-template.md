# Review coverage record

Resolve this record's location from the consumer review source directory.

| Field | Authored value |
| --- | --- |
| Mode | full / scoped |
| Date and source revision | commit, dirty state and baseline |
| Declared scope | components, production paths and behaviors |
| Opened files | explicit checkout-relative filenames |
| Traced behaviors | entry points, effects, failure and retry |
| Evidence | lane ID, retained run, freshness and proof boundary |
| Omissions | unexamined paths and why |
| Prior findings not examined | canonical IDs and unchanged prior dispositions |
| Limits and release posture | authored judgment supported by stated evidence |

Do not infer implementation coverage from generated inventory or passing tests. Preserve dated records when reassessing.

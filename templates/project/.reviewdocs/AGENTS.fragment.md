# Documentation routing (merge into existing AGENTS.md if appropriate)

For factual architecture/domain/API/workflow documentation, use the repository's `system-reference` skill. For a formal engineering review or reassessment, use `evidence-review`. For illustrated user tasks, troubleshooting and app help, use `user-guide`.

Consumer evidence commands and product conventions belong in `reviewdocs.config.mjs` and consumer-owned documentation. Toolkit upgrade does not authorize a review, remediation, installation into a live app or deployment.

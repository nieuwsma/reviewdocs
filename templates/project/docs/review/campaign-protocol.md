# Review campaign protocol

1. Record the exact source and comparison baselines.
2. Generate fresh machine evidence in isolated output directories.
3. Inspect implementation and executable behavior rather than trusting prose.
4. Reassess every existing finding and search for regressions.
5. Keep descriptive documentation separate from evaluative findings.
6. Regenerate the static sites and validate deterministic output, links, and anchors.
7. Report failed tests and unavailable evidence explicitly.

A failing product test is evidence. A contaminated or non-reproducible evidence set is a review-process failure.
